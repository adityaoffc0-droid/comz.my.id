       Features & Shortcuts

      Projects

      • Multiple projects, each holding its own set of files
      • Home screen lists every project — name, file count, last-edited time
      • Create, rename and delete projects
      • Export any project as a downloadable .zip archive
      • Import a .zip archive as a new project
      • Everything autosaves to on-device local storage — fully offline, no account

      Files & Tabs

      • Multi-file tabbed editing inside a project
      • Dedicated "Select File" sidebar to jump between or remove files
      • New file, open a file from the device, rename (double-tap a tab), delete
      • Unsaved-changes dot indicator per tab
      • Confirmation before closing a file with unsaved changes
      • Save a single file or Save All files to the device

      Languages

      • Syntax highlighting for 21 languages: JavaScript, TypeScript, JSX, JSON, HTML, CSS, Python, XML, C, C++, Java, C#, PHP, SQL, Markdown, Shell, YAML, Ruby, Go, Rust, Swift, Plain Text

      Editing Tools

      • Find & Replace
      • Go to Line
      • Select All
      • Duplicate Line
      • Delete Line
      • Move Line Up / Down
      • Toggle Line Comment
      • Indent / Outdent
      • UPPERCASE / lowercase selection
      • Trim trailing whitespace
      • Sort lines A–Z
      • Format / beautify (JSON pretty-print + basic brace re-indent)
      • Toggle word wrap
      • Toggle auto-close brackets
      • Copy entire file to clipboard
      • Bracket matching & code folding
      • Active-line highlighting & line numbers
      • Undo / redo

      Run & Debug

      • Live HTML preview in a sandboxed frame
      • Error detection for JS, JSON, Python and bracket mismatches
      • Auto-delete offending lines
      • In-browser Python runner (Pyodide)
      • Simulated terminal panel plus a quick bottom terminal dock

      Interface

      • Dark / light theme
      • Adjustable editor font size
      • Fullscreen mode
      • Custom vector icon set throughout — no emoji
      • Status bar: language, char/line count, cursor position, autosave state
      • Toast notifications for quick feedback
      • Custom in-app popups for language picking and confirmations (no native browser dialogs)
